How to verify a download

  1. Download the file from one of the sources above, and its SHA-256 checksum.
  2. Get the file’s fingerprint. In the folder with the file, right-click an empty spot and choose Open in Terminal (on Windows 10: Shift + right-click, Open PowerShell window here). Then run this, with your file’s name: 
    Get-FileHash .\file.exe -Algorithm SHA256
  3. Compare. The Hash it prints must match the line for the same file name in the checksum file, or the SHA-256 shown on this site. Upper or lower case doesn’t matter.

If the two don’t match, don’t open the file. Delete it and download it again from this page.
