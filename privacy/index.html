Privacy

Short version: our apps do not collect anything about you.

  • No telemetry or analytics. The apps do not send usage data, crash reports or identifiers anywhere.
  • Your files stay on your PC. InstaFind's index, Remember Me's tasks and Lemon's chats are stored only on your computer.
  • No account. Nothing to sign up for.
  • Internet use: only to check GitHub for updates, and in Lemon to download an AI model you choose. InstaFind's web shortcuts open your browser only when you ask.
  • This website uses no cookies and no trackers. It is hosted on GitHub Pages, which may keep standard server logs. The home page asks the public GitHub API for the latest version numbers.
  • Feedback you post on GitHub is public and covered by GitHub's privacy policy.

All the code is open source, so you can check every claim above on GitHub. Questions? Open an issue.
