Privacy policy

Privacy

FastKiwi apps have no accounts, ads, analytics or telemetry. Your data stays on your PC. This page lists every network connection each app makes, what it sends and when.

Effective date: November 3, 2026

This policy covers the Windows apps InstaFind, Remember Me, Lemon and InstaWords, the InstaWords web app and the fastkiwi.app website, all published by FastKiwi. All the code is open source, so you can check each point below in the source code.

What applies to every app

  • No account, ads, analytics or telemetry. None of the apps sends usage statistics, crash reports or identifiers anywhere on its own.
  • Your data stays on your PC. The files each app keeps are listed below, with their folders, so you can see, copy or delete them.
  • We don’t receive, sell or share your data. FastKiwi runs no servers that receive data from the apps.
  • Feedback is your choice. “Report a problem” and similar buttons open a pre-filled GitHub issue in your browser. You can read and edit it first. Issues you post on GitHub are public and covered by GitHub’s privacy statement.
  • Links open in your browser. When you click a link in an app, the site it opens has its own privacy policy.

The apps, one by one

InstaFind · file search

Stored on your PC

  • In %LOCALAPPDATA%\BahthSari: the index of file and folder names on your drives (index.bin), the index of text inside your documents (the content files, when content search is on), your recent and saved searches and which files and results you open most (history.json), settings (settings.txt), cached exchange rates (rates.json), a log (log.txt) and crash reports (crash.txt).
  • Some settings, such as the interface language and the phone search switch, PIN and secret link, are kept in the Windows registry under HKCU\Software\BahthSari.
  • Text in images is read by the OCR engine built into Windows, on your PC. Nothing is uploaded.

Network connections

  • Update check: about 10 seconds after start and then at most once a day, InstaFind asks GitHub (api.github.com, or the release page on github.com if the API is busy) for the latest version. It sends nothing but the request and the app’s name and version (in the user-agent). A new version is downloaded from GitHub only after you choose to update. The automatic check can’t be turned off at the moment.
  • Exchange rates: for currency answers in the quick search (“100 usd to iqd”), InstaFind downloads a public table of rates from open.er-api.com when the saved rates are over 12 hours old: shortly after start while the quick search is enabled (it is by default), or when you open it. Only the table is requested, with the app’s name and version; your query is not sent, and the conversion is done on your PC.
  • Search from phone (Options, off by default): when you turn it on, InstaFind runs a small read-only web server on your home network. Devices with the PIN or the secret link can search your file names, and download files only if you also allow downloads. It accepts only private home-network addresses and never the internet. This traffic stays on your local network and is not encrypted (plain HTTP).
  • Web shortcuts such as “youtube …” or “google …” open your browser on that site with your words, only when you choose that result.
  • Feedback and crashes: “Send feedback” opens a pre-filled GitHub issue with the app version, Windows version, processor type and interface language. After a crash, InstaFind asks once whether to report it. If you choose yes, the issue also contains the crash report (error message, place in the code, technical addresses). Nothing is sent unless you submit the issue.

Remember Me · tasks & reminders

Stored on your PC

  • In %APPDATA%\Remember Me (or the data folder you move it to): your tasks, notes, attachments and settings (data.json and the attachments folder), automatic and safety backups (backups), the Drive backup settings (drive-backup.json) and a log (logs\remember-me.log). The log is local only.
  • Backups you export go to the folder you choose. Uninstalling keeps your data folder.

Network connections

  • Updates, only with your consent: Remember Me first asks whether it may check for updates. Only if you allow it does it check GitHub Releases for the Remember-Me repository, about 30 seconds after start and then once a day, and download a new version, which installs when you restart or quit. Check now does the same once, at any time. None of your data is included. You can turn this off in Settings, Updates.
  • Google Drive backups: Remember Me never connects to Google. It has no Google sign-in, asks for no Google permissions and stores no Google passwords or tokens. It copies the backup (your tasks, notes and attachments) into a folder you choose on your PC. If that folder is synced by Google Drive for desktop, Google’s app uploads the copy to your Google account, under Google’s privacy policy. The “Install Google Drive and sign in” button opens Google’s download page in your browser.
  • Report a problem: opens a pre-filled GitHub issue with the app and Windows versions, processor type, language, theme and the last 30 lines of the log with folder paths and quoted text removed. It never includes your tasks, notes or file names, and nothing is sent unless you submit it. Copy diagnostic info only copies versions, language and theme to your clipboard.

Lemon · local AI chat

Stored on your PC

  • In %APPDATA%\LocalAiChat: your conversations, settings (settings.json), assistants and the documents you give them, with the text and search index made from those documents. After a crash, Lemon writes the error to crash.txt in the same folder and shows a notice next time. It never sends it.
  • The window’s browser profile and cache are in %LOCALAPPDATA%\LocalAiChat\webview, and exports in Documents\LocalAiChat. With the LOCALAI_DATA_DIR variable set, everything is kept in that folder instead.

Network connections

  • Ollama: your messages, the conversation so far and the text of documents you give an assistant (to index them and to answer from them) go to the Ollama server Lemon is set to, http://127.0.0.1:11434 on your own PC by default, which runs the AI model. If you change that address in Settings to another computer, this data goes to that computer.
  • Lemon’s own server listens on 127.0.0.1 only, so other devices on your network can’t reach it.
  • Models: when you download a model, Ollama fetches it from its registry. That download is made by Ollama, under Ollama’s terms.
  • Update check: on by default; at start and every 6 hours Lemon asks GitHub (api.github.com) for its latest release. No chats or files are included. A new version is downloaded from GitHub only when you click Update now. You can turn the automatic check off in Settings.
  • Code preview: when you click Run on a code block, it runs in an isolated frame. If that code loads scripts, images or data from the internet, the preview fetches them like a web page would.
  • Lemon’s window is drawn by Microsoft Edge WebView2, a part of Windows. Microsoft’s own Windows privacy settings apply to it.

InstaWords · amounts in words

Windows app: stored on your PC

  • In %APPDATA%\FastKiwi\InstaWords: settings (settings.json), the history of your last 100 conversions, that is each amount and its words (history.json, which you can clear in the app), and a crash log (crash.log, and crash.old.log once it passes 256 KB). The crash log holds the time, app version, the error and where it happened, never amounts, and it is never sent anywhere.

Windows app: network connections

  • Update check: on by default; a few seconds after start, at most once a day, InstaWords asks GitHub (api.github.com) for its latest release, sending only the app name and version. A new version is downloaded from GitHub only after you choose to install it. You can turn the automatic check off in Settings.
  • Report a problem or suggestion: you write the report and see a preview. By default it includes technical details: app version and install type, Windows and .NET versions, interface language and Windows region, display scale, conversion options (language, currency, form of “hundred”, decimals), the hotkey and the last error code. Untick the box to leave them out. Amounts, the clipboard and the history are never included. The report opens as a pre-filled GitHub issue in your browser, or you can copy it. Nothing is sent unless you submit it.

Web app (fastkiwi.app/instawords/)

  • Conversion runs entirely in your browser. The amounts you type are never sent anywhere.
  • Your browser’s local storage keeps your preferences (language, currency, form of “hundred”, decimals, prefix and suffix) and, for an hour, the latest Windows release details. A service worker keeps a copy of the site’s own files so it works offline.
  • To show the latest Windows version, the page asks api.github.com directly from your browser, without cookies or referrer.

This website, fastkiwi.app

  • No cookies, analytics, ads or trackers. Fonts, images and scripts are served from fastkiwi.app itself; no third-party scripts or fonts are loaded.
  • Hosting: the site is hosted on GitHub Pages. Like any web server, GitHub receives your IP address and browser details with each request and may log them, under GitHub’s privacy statement. FastKiwi does not get these logs.
  • Version numbers: pages with download buttons or release notes (the home page, What’s new, Lemon and InstaWords) ask the public GitHub API (api.github.com) for the latest versions, directly from your browser. The answer is kept in your browser’s local storage for an hour, so the page doesn’t ask again on every visit. Nothing about you is stored there.
  • Downloads come straight from each app’s release on GitHub. Links that take you to GitHub are labelled “GitHub”.

Changes to this policy

When an app starts using the network in a new way, we update this page before that version is released and change the effective date above. Each app’s release notes on What’s new describe its changes.
