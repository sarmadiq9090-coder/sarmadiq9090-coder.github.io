Game localizations

A community translation covering the menus, settings, upgrades, collection, and dialogue.

For Steam 1.0.7, build 26836748, on Windows x64.

Download Arabic installer ↓

How to install

  1. Close the game. In your Steam library, right-click Sardoinky and choose Manage → Browse local files.
  2. Put the downloaded installer next to sardoinky.exe and run it. Windows may ask for permission to write to the folder.
  3. Start the game from Steam. Choose Arabic under Settings → Language if needed.

Tested on Windows 11 25H2. The installer includes a compatibility path for Windows 10 version 1703 and later, which still needs direct testing.

Remove the localization

In Steam, open Properties → Installed Files → Verify integrity of game files. A Steam update can also replace the localized file.
