The localization

What is translated?

  • 1346 strings in seven sections
  • Menus, settings, dialogue and the shop
  • Upgrades, the collection, fish and achievements

Install

  • Close the game, then in Steam: Manage → Browse local files
  • Put the localization file next to sardoinky.exe and run it; Windows may ask for permission to write to the folder
  • Start the game and choose Arabic in Settings → Language

Remove

  • Close the game
  • In Steam: Properties → Installed Files → Verify integrity of game files
  • Steam puts the game back as it was

Before you start

An unofficial community localization for Steam version 1.0.7. Some text inside images and logos is still in English. If Steam updates the game, its original file may come back, so run the localization file again. Tested on Windows 11 25H2; it includes a compatibility path for Windows 10 version 1703 and later that has not been tested yet.
