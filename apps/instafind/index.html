What it does

Understands Arabic

  • Finds «أحمد» when you type «احمد» without the hamza
  • Finds a word with or without «ال»
  • Copes with typos and Arabizi

Fast and smart

  • Results appear while you type
  • Finds Arabic typed on an English keyboard layout
  • Searches inside PDF and Word files

Easy to use

  • Open the file or its folder in one click
  • Copy the path or export the results
  • A history of your recent searches

What’s new in 1.2.0?

  • A calmer message when the update server can’t be reached
  • Updated libraries
