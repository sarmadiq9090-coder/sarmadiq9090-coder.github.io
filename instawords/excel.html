InstaWords لـ Excel

إضافة Excel مجانية · بلا إنترنت · بلا اشتراك

التفقيط داخل Excel، على جهازك دون إنترنت

إضافة واحدة تثبّتها في Excel مرة واحدة، فتصبح الدالة TAFQIT متاحة في كل مصنف تفتحه. تعمل محلياً بلا اتصال، وتعطي النص نفسه الذي يعطيه InstaWords في المتصفح.

تنزيل الإضافة InstaWords.xlam (تجريبية) طريقة التثبيت

ملف واحد يحوي الدالة وكل العملات والوحدات · Excel لويندوز. ولـ macOS أو لمصنف واحد: Tafqit.bas (الطريقة).

تثبيت الإضافة مرة واحدة

  1. ضع الملف InstaWords.xlam الذي نزّلته في مجلد ثابت لن تحذفه، مثل مجلد InstaWords داخل «المستندات». فـ Excel يحمّل الإضافة من مكانها كل مرة.
  2. إلغاء الحظر أولاً: انقر الملف بزر الفأرة الأيمن ← «خصائص» ← في أسفل تبويب «عام» فعّل «إلغاء الحظر» (Unblock) ← «موافق». يضع Windows على كل ملف منزَّل من الإنترنت علامة تجعل Excel يحظر الماكرو فيه، فلا تعمل الدالة دون هذه الخطوة. (إن لم يظهر الخيار فالملف غير محظور.)
  3. في Excel: «ملف» ← «خيارات» ← «الوظائف الإضافية» ← في «إدارة» اختر «وظائف Excel الإضافية» ← «انتقال…» ← «استعراض…» ← اختر InstaWords.xlam ← «موافق». (File → Options → Add-ins → Manage: Excel Add-ins → Go… → Browse…)
  4. تأكّد أن «InstaWords» محدد في القائمة ثم «موافق». الآن اكتب في أي مصنف =TAFQIT(A1, "SAR")، ولا حاجة لحفظه بصيغة .xlsm.

الإضافة مبنية وفق مواصفات ملفات Excel ومختبرة آلياً بقراءة الملف الناتج، لكنها لم تُجرَّب بعد في Excel حقيقي. إن لم تعمل لديك فاستخدم طريقة Tafqit.bas وأخبرنا عبر «الإبلاغ عن مشكلة» أسفل الصفحة.

الاستخدام

اكتب في أي خلية الصيغة التالية، حيث A1 خلية المبلغ:

=TAFQIT(A1, "ريال سعودي", "مائة", "فقط", "لا غير")

فإن كان في A1 الرقم 2500 كانت النتيجة:

فقط ألفان وخمسمائة ريال سعودي لا غير

المعاملات بعد الرقم اختيارية؛ فالصيغة =TAFQIT(B2, "SAR") تكفي في أغلب الأحوال.

إن ظهر تنبيه أمني: مركز التوثيق

إن أظهر Excel عند تشغيله تنبيهاً أمنياً بشأن الإضافة، أو أعادت الدالة #NAME?، فالطريقة الأكثر أماناً أن تجعل مجلد الإضافة «موقعاً موثوقاً»:

  1. «ملف» ← «خيارات» ← «مركز التوثيق» ← «إعدادات مركز التوثيق…».
  2. «المواقع الموثوقة» ← «إضافة موقع جديد…» ← اختر المجلد الذي فيه InstaWords.xlam ← «موافق».
  3. أغلق Excel وافتحه من جديد.

لا تختر «تمكين كل وحدات الماكرو» في «إعدادات الماكرو»: فهو يسمح لأي ملف بتشغيل برامج على جهازك. الإعداد الافتراضي («تعطيل كل وحدات الماكرو مع الإعلام») مع موقع موثوق يكفي.

بديل: وحدة Tafqit.bas في مصنف واحد

لـ Excel على macOS، أو إن أردت الدالة داخل مصنف بعينه يُرسَل إلى غيرك. نزّل Tafqit.bas ثم:

  1. افتح المصنف في Excel، ثم اضغط Alt + F11 لفتح محرر Visual Basic (على Mac: Option + F11، أو من قائمة «أدوات ← ماكرو ← محرر Visual Basic»).
  2. من قائمة File اختر Import File… وحدّد الملف Tafqit.bas الذي نزّلته.
  3. أغلق المحرر، واحفظ المصنف بصيغة «مصنف Excel ممكَّن بماكرو» (.xlsm) حتى تبقى الدالة معه.

إن ظهر تنبيه أمني عند فتح المصنف لاحقاً فاختر «تمكين المحتوى». وإن حظر Excel وحدات الماكرو في ملف منزَّل من الإنترنت، فافتح خصائص الملف في Windows وفعّل خيار «إلغاء الحظر».

In English

InstaWords.xlam (experimental) is an Excel add-in that adds =TAFQIT(Number, [Unit], [HundredsForm], [Prefix], [Suffix], [Decimals], [Language]) to every workbook, offline. =TAFQIT(A1, "SAR", "", "", "Only", "", "en") gives English, "fr" French.

  1. Save the file in a folder you will keep. Right-click it → Properties → tick Unblock → OK (Windows marks downloaded files, and Excel blocks their macros).
  2. Excel → File → Options → Add-ins → Manage: Excel Add-ins → Go… → Browse… → pick InstaWords.xlam → OK, and make sure InstaWords is ticked.
  3. If Excel shows a security notice or #NAME?: Trust Center → Trust Center Settings… → Trusted Locations → Add new location… and add the add-in's folder. That is safer than enabling all macros.

Built to the file-format specifications and verified by parsing the produced file, but not yet tried in a real Excel. If it does not work for you, import Tafqit.bas instead (Alt+F11 → File → Import File…, save as .xlsm) and please report it.

المعاملات

#المعاملالوصف
1الرقمخلية أو قيمة. يقبل النص أيضاً، بالأرقام العربية أو الإنجليزية.
2الوحدةاسم الوحدة كما في قائمة الموقع («ريال سعودي»، «دينار كويتي»، «كيلوغرام»…) أو رمزها مثل "SAR". اتركه فارغاً للعدد بدون وحدة.
3رسم المئة"مائة" (الافتراضي) أو "مئة".
4نص قبل المبلغاختياري، مثل «فقط».
5نص بعد المبلغاختياري، مثل «لا غير».
6الخانات الزائدة"round" (الافتراضي) لتقريب الكسر إلى أقرب جزء من العملة، أو "error" لإظهار خطأ.

وعند وجود خطأ في الرقم تعيد الدالة رسالة عربية تشرح السبب بدل النص. وتعيد الدالة =TAFQIT_CLEAN(A1) الرقم بعد تنقيته، مثل 123.45 للمدخل ١٢٣٫٤٥.

للمطوّرين: مكتبة JavaScript

النواة نفسها التي تشغّل هذا الموقع مكتبة صغيرة بلا أي اعتماديات، تعمل في المتصفح وفي Node.js. مجلد lib/ في هذا الموقع نسخة جاهزة منها، ويمكنك بناؤها من المستودع بالأمر npm run build.

import { tafqit, tryTafqit, createTafqit } from "./lib/index.js";

tafqit("1250.75", { unit: "SAR" });
// "ألف ومائتان وخمسون ريالاً سعودياً وخمس وسبعون هللة"

tafqit("2500", { unit: "SAR", prefix: "فقط", suffix: "لا غير" });
// "فقط ألفان وخمسمائة ريال سعودي لا غير"

const r = tryTafqit("abc", { unit: "SAR" }); // لا يرمي استثناءً
if (!r.ok) console.log(r.error.code, r.error.message);

// وحدات مخصّصة: عدّل units.json ثم ابنِ محركاً منه
const engine = createTafqit(await (await fetch("units.json")).json());
engine.tafqit("300", { unit: "SAR", hundredsForm: "مئة" });

الخيارات: unit وhundredsForm وdecimals ("round" للتقريب أو "error") وprefix وsuffix. التفاصيل الكاملة في مستودع المشروع على GitHub.
